THE OMEGA ARCHIVE — PROJECT 035
PLAYER WEBSITE

FILES
- index.html: main website
- css/style.css: visual design
- js/cases.js: player-facing investigation content and browser-side answer checks
- js/app.js: unlocking, progress, hints, and reset logic

RUN LOCALLY
Open index.html in a modern browser. For best results, use a local development server.

PUBLISH ON GITHUB PAGES
1. Extract this ZIP.
2. Upload index.html, css/, and js/ to the ROOT of your repository.
3. Open repository Settings → Pages.
4. Select Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish.

IMPORTANT
This is a static puzzle game. Answers are stored in client-side JavaScript and can be discovered by inspecting the source. It is not a secure challenge platform. Keep the creator answer key separate and never upload it to the public repository.

All digital systems and network references are fictional and simulated.
